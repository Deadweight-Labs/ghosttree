Login required

Diese Aktion braucht eine Anmeldung per Login (OIDC oder Login-Link), nicht per eingefügtem Token.

This action needs a sign-in by login (OIDC or a one-time login link), not by a pasted token. A pasted token also sits in the config of every machine an agent runs on, so it only gives a read-only session.

Without OIDC, the operator creates a login link on the server host with ctx account login-link <name> --url https://host --db <path>. Open the link, confirm it, and the new session can change roles, memberships, invitations and devices. Sign-in page
